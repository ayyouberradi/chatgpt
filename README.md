# Laravel website — Hostinger deployment package

Download [chatgpt-hostinger.zip](https://github.com/ayyouberradi/chatgpt/raw/refs/heads/main/chatgpt-hostinger.zip), then follow [HOSTINGER.md](HOSTINGER.md).

The ZIP contains the Laravel application, production PHP dependencies, and compiled React frontend. Laravel belongs outside the public document root; the package provides sibling `laravel` and `public_html` folders. PHP 8.4 or newer is required.

The archive contains no credentials, application key, or populated database. Initialize the application and create your administrator using the deployment instructions. This package has been validated locally; it has not yet been deployed to Hostinger.
